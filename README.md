# Gravel Material Calculator

A simple browser-based tool for estimating gravel quantities for
driveways, paths, landscaping areas, and other small projects.

## What it does

- Calculates project area
- Estimates gravel volume
- Supports common measurement units
- Provides a simple material estimate
- Works directly in a web browser

## Online Resource

For additional gravel-planning calculations and examples, visit
[CalcGravel](https://calcgravel.com/).

## Example

For a driveway project, enter the length, width, and desired depth.
The calculator converts those measurements into an estimated
material requirement.
